# Procrastination Roast Machine 🔥

An AI-powered application designed to destroy your procrastination excuses and push you into action using hilarious, customizable roast personalities like Gordon Ramsay, Indian Mom, or an Evil AI.

## 🚀 Features

- **Custom Roast Personas:** Select personalities to critique your excuses.
- **Interactive Inputs:** Type in the exact coding or personal task you're dodging and receive immediate, witty feedback.

## 🛠️ Tech Stack

- **Node.js** (>=20)
- **JavaScript / ES Modules**
- **Zod** (Schema Validation)
